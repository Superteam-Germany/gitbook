# 🔥 Get Involved

The easiest way to get value from Superteam Germany is to show up consistently.

## Start Here

1. Join the community channels
2. Follow the event calendar on Luma
3. Attend an event or guild session
4. Pick a build track from [Build on Solana](../build-on-solana/README.md)
5. Join the next hackathon or Build Station

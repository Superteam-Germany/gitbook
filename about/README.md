# 🇩🇪 About Superteam Germany

Superteam Germany is a local Solana community for people who want to learn, build, and grow inside the ecosystem.

We focus on practical support:

- helping builders get started faster
- connecting founders, developers, creators, and ecosystem operators
- running events, guilds, and hackathon support programs
- curating high-signal resources instead of making people search from scratch

These docs are not meant to duplicate the website. They are the working handbook for people who want to do something concrete: join, build, ship, and participate.

# 👋 Start Here

Superteam Germany is the local home for builders, developers, and ambitious operators who want to learn, ship, and grow on Solana.

These docs are designed to help you:

- understand what Superteam Germany is and how to get involved
- find the right program or event
- get productive on Solana faster
- prepare properly for hackathons like Colosseum
